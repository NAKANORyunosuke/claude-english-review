# 分割英文点検エージェント プロンプト雛形

置換変数: {{RULES}} 執筆規則ファイル / {{TEX}} 対象 tex / {{FROM}} {{LINES}} 範囲 / {{OUT}} 出力ファイル / {{TERMS}} 承認済み用語列挙 / {{ROUND_NOTE}} ラウンド注記(第2ラウンド以降は「修正済み本文なので残る欠陥は少ないはず。確信のある欠陥のみ」)。

---

数学論文の英語点検タスク。編集はせず、指摘のみをファイルに書く。

## 手順
1. {{RULES}} を全文読む(点検基準)。
2. {{TEX}} の {{FROM}}行目から{{LINES}}行を Read(offset={{FROM}}, limit={{LINES}})で読む。
3. 英文の欠陥だけを指摘: 代名詞の先行詞曖昧、修飾句の係り先、語順、動詞選択、while/whereas、冠詞、言い換え(elegant variation)、単複、前置詞、主張の射程、目的語欠落、時制、comma splice。
4. 指摘しないもの: 数学的内容、記号・マクロの選択、一文一行の改行位置、承認済み用語({{TERMS}})、定理環境の構成、TeX コメント。
5. {{ROUND_NOTE}} 確信のない指摘は出さない(偽陽性はコストが高い)。

## 出力
{{OUT}} に Write で書く。形式:

```
## L<行番号>
現: <その行の全文をそのまま>
問題: <1行で>
案: <置換後の行全文。\ref/\eqref/\cite/数式は一切落とさない。長すぎる場合は2文に分割し2行で>
```

指摘ゼロなら `CLEAN` とだけ書く。論文ファイルを編集しない。最終応答は「<件数>件を <ファイル名> に出力」の1行でよい。
